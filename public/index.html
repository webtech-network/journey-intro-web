Ponto de Partida

Configure o Ambiente JSON Server

O JSON Server é o coração desta disciplina. Ele permite simular um backend completo com uma API REST totalmente funcional em minutos, sem precisar programar o servidor.

Com ele, você vai fazer requisições HTTP reais (GET, POST, PUT, DELETE) para persistir dados, exatamente como acontece em aplicações profissionais.

Guia de Configuração Completo →

// Exemplo rápido com Fetch API

fetch('http://localhost:3000/api/contatos')

.then(res => res.json())

.then(dados => {

// dados é um array de contatos

console.log(dados)

})
