Ponto de partida

Configure o ambiente JSON Server

O JSON Server é o coração desta disciplina. Ele permite simular um backend completo com uma API REST funcional em minutos, sem precisar programar o servidor.

Com ele, você faz requisições HTTP reais (GET, POST, PUT, PATCH e DELETE) para persistir dados, exatamente como acontece em aplicações profissionais.

Guia de configuração
javascript api/contatos 
fetch("/api/contatos")
  .then((res) => res.json())
  .then((dados) => {
    // dados é um array de contatos
    console.log(dados);
  });
JSON Server rodando na porta 3000
