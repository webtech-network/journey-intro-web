Visualização de Dados com Chart.js

Demonstra como transformar dados brutos do JSON Server em gráficos interativos usando a biblioteca Chart.js. Os dados financeiros são agrupados por mês e por categoria para gerar um gráfico de barras empilhadas e um gráfico de pizza.

Conceitos trabalhados

Carregar Chart.js via CDN

<script src="https://cdn.jsdelivr.net/npm/chart.js">
Não requer instalação — disponível diretamente no navegador.

Estrutura de dados do Chart.js

Cada gráfico precisa de labels (eixo X) e datasets (séries de dados), cada uma com cor e valores.

Agrupamento com Set e filter/reduce

[...new Set(data.map(d => d.mes))] extrai valores únicos.
.filter().reduce() soma os valores por grupo.

Canvas HTML5

Chart.js renderiza dentro de um elemento <canvas>. Cada canvas deve ter um ID único referenciado no JavaScript.

Padrão: dados → gráfico

javascript 
// 1. Buscar dados do JSON Server
const data = await fetch('/api/lancamentos').then(r => r.json());

// 2. Extrair dimensões únicas
const meses      = [...new Set(data.map(d => d.mes))];
const categorias = [...new Set(data.map(d => d.categoria))];

// 3. Montar datasets (uma série por categoria)
const datasets = categorias.map((cat, idx) => ({
  label: cat,
  data: meses.map(mes =>
    data.filter(d => d.mes === mes && d.categoria === cat)
        .reduce((acc, cur) => acc + cur.valor, 0)
  ),
  backgroundColor: CORES[idx]
}));

// 4. Criar o gráfico no canvas
new Chart(document.getElementById('meuGrafico'), {
  type: 'bar',
  data: { labels: meses, datasets },
  options: { scales: { y: { beginAtZero: true, stacked: true }, x: { stacked: true } } }
});
